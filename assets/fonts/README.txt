TIPOGRAFIA OFICIAL - ADOBE FONTS

A partir da versao 1.4.3, a fonte Nexa e carregada pelo kit Adobe Fonts:
https://use.typekit.net/pwt1xky.css

NAO e necessario baixar ou enviar arquivos OTF/TTF/WOFF para o GitHub.
NAO use os arquivos Trial da familia Nexa: a licenca recebida para estes
arquivos tinha uso exclusivamente pessoal.

O kit Adobe define as familias CSS "nexa" e "nexa-text", com 400 e 700.
O site usa a familia CSS "nexa" no peso regular 400, conforme a direcao
editorial aprovada. Bold fica disponivel para uso futuro se desejado.

A exibicao depende do projeto web de Adobe Fonts e da assinatura elegivel
que o mantem ativo. Se o servico nao carregar, as fontes de fallback
configuradas em assets/css/styles.css sao usadas.

Se houver OTFs previamente enviados em assets/fonts no GitHub,
remova-os para nao manter copias locais desnecessarias.
